## Scope and evidence standard

This pass supplies evidence for D03 (documents/news), D06 (geographic/space sources), D07 (cameras), D08 (radio), and D11 (markets), as defined in the [decision register](../delivery.md#6-decision-register). It does not resolve those decisions. The [source registry contract](../architecture.md#4-source-adapters-and-ingestion) and [product specification](../spec.md) remain authoritative.

The survey is deliberately US-heavy for government records and regional context, with global scientific and Earth-observation candidates. No first deployment region has been selected. Non-US government archives, regional publishers, court records, procurement, corporate registries, and additional camera/radio operators need subsequent research. Device integrations are outside this public-source survey.

Evidence labels used below:

- **Documentation read:** substantive provider documentation or a public collection listing was retrieved and inspected. This does not establish API or asset access.
- **Sample checked:** a bounded unauthenticated request returned JSON and the stated fields were inspected. This establishes only that request's result at retrieval time.
- **Unresolved access:** an HTTP failure, timeout, or thin HTML shell prevented substantive verification. It is not proof that the source is unavailable to everyone.
- **Proposed:** an OIA recommendation or next step, not a provider claim or implementation result.

Access, automated processing, retention, and redistribution are separate decisions. In the tables, **unresolved** means this pass did not establish the relevant permission or constraint; it does not mean prohibited. No source content license is inferred from a public URL, a government domain, an API response, or a website footer. Restrictions on third-party material must survive export.

## Initial findings that affect implementation

1. **Historical reconstruction needs explicit archives.** OpenSky documents only current state vectors for anonymous users and up to one hour for authenticated users on that operation. NWS operational products are not a substitute for an established weather archive. A camera directory is not evidence that historical recordings exist.
2. **Metadata is often the easiest first acquisition.** Crossref returned a DOI record; CMR returned a collection record. Neither response establishes access to the associated paper or scientific image. Retain exact identities and rights references before retrieving assets.
3. **Public government collections still need item-level review.** GovInfo explicitly warns that government publications can contain copyrighted material. FBI and CIA documents also need release, page, redaction, and originating-source identities, rather than treating each hosted copy as independent corroboration.
4. **Access policies have changed enough to make remembered defaults unreliable.** Current OpenSky documentation specifies OAuth2 for authenticated use; ReliefWeb requires a pre-approved app name; OpenAlex distinguishes keyless queries from keyed paging and budgeted use. These are documented conditions, not tested account entitlements.
5. **FRED is not ready to select for OIA's AI workflows.** Its reviewed terms prohibit use in connection with development or training of software/AI systems in broad language. Series also carry different third-party rights. Clarify applicable use before selecting it for programmatic OIA ingestion or AI processing; do not assume that “free data” resolves the issue.
6. **Successful transport can still provide no useful source content.** Marine Cadastre, 511NY, and WebSDR returned minimal shells in this environment. They remain leads. AARO, SEC, NUFORC, and BLS returned 403 responses; no alternate access was attempted to evade those restrictions.

## Actual probe evidence

[source-checks.json](source-checks.json) records all 53 initial requests, including failures, initial mistaken JPL URLs, redirects, retrieval timestamps, MIME types, received body byte counts and SHA-256 where complete, and small inspected result summaries. It contains no credentials or retained response bodies. Hashes refer to complete response bodies delivered by the HTTP client after transport decompression, before text extraction; they demonstrate byte identity only. The documents cited above remain the source of provider claims.

The research helper ran locally on Windows with Python 3.12.10 and Requests 2.34.2; it is a temporary research tool, not OIA production code. It used GET only, no authentication, four workers across sources, no automatic retry, 8-second connection / 15-second read timeouts, a 2 MiB response cap and a 25-second elapsed check while streaming. This is not a hard end-to-end deadline across redirects or blocked reads. API samples were single requests per service. No bulk downloads, hidden endpoints, account creation, hosted CI, device connections, or restricted-source bypasses were used.

## Proposed first acquisition slice

This is a research recommendation for the existing package owners, not a provider-selection ADR or a claim on their work:

3. **Bounded event ingestion:** use a small USGS query to exercise pagination/completeness, update identity and provenance once #13's contracts are available. Keep deliberate sample caps visible.

## Required evidence for the next research pass

- **Every selected product:** provider/listing URL, exact record and revision, retrieved UTC, content type/size/hash where retained, original/publication/revision/event/capture times, coverage and pagination, units/reference systems, attribution, and separate automation/retention/redistribution decisions with dated policy references.
