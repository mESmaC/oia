# ALPR / Flock camera corridor fixture (`new-meridian-corridor-fixture.json`)

Synthetic OpenStreetMap Overpass-compatible node fixture for validating OIA's mapped ALPR / Flock camera directory kernel ([`crates/oia-alpr-map`](../../../crates/oia-alpr-map/README.md)) and interactive map prototype ([`docs/design/mockups/flock-camera-map.html`](../../../docs/design/mockups/flock-camera-map.html)) under requirement [`CAM-06`](../../../docs/spec.md#51-internet-cameras-and-anomaly-detection).

- **Origin class and fictional scope (`AGENTS.md` §2):** Synthetic test fixture (`origin: "synthetic-fixture"`, `"synthetic": true`). Both the geography (`New Meridian Synthetic Corridor`, `37.605..37.635 N`, `-121.915..-121.875 E`, with fictional roadways `Meridian Axis Blvd`, `Harbor Gate Causeway`, `North Spire Transit Way`, `Kestrel Commons Pkwy`, and `Solstice Ridge Way`) and all named operators (`New Meridian Municipal Transit Authority (Synthetic)`, `Aegis Harbor District Patrol (Synthetic)`, `Kestrel Commons Commercial HOA (Synthetic)`, `North Spire Institute Safety (Synthetic)`, `Vanguard Plaza Parking Cooperative (Synthetic)`, `Solstice Ridge Civic Association (Synthetic)`, and `New Meridian Regional Roadway Authority (Synthetic)`) are invented for deterministic testing and do not represent any real municipal deployment. Any URLs in fixture tags use the reserved `.invalid` TLD (RFC 2606).
- **Reserved synthetic OSM node ID range (`>= 900_000_000_000`):** Every fixture element uses an ID in the reserved synthetic range `900_000_000_101`..`900_000_000_199` (`>= 900_000_000_000`, well above current OpenStreetMap node sequences) so synthetic test nodes can never collide with real OpenStreetMap node IDs.
- **Per-record synthetic markers:** Every element in `new-meridian-corridor-fixture.json` carries `"synthetic": true` on the node object plus `"note": "SYNTHETIC FIXTURE - NOT OBSERVED"` and `"oia:synthetic": "true"` inside `tags` (along with `SYNTH-NM-xxx` references), ensuring the synthetic provenance marker survives single-node or tag-map extraction.
- **Not live or retained field evidence (`CAM-06`):** Node IDs, coordinates, operator strings, `check_date` / `survey:date` values, and `osm_timestamp` values are deterministic fixture inputs for testing normalization, manufacturer classification (`FlockSafety`, `OtherNamed`, `Unspecified`), semicolon tag parsing (`camera;ALPR`), bearing edge cases (blank/whitespace, cardinal words `"NE"`, `"360"` wrap to `0.0`), non-ALPR exclusion (`900_000_000_199`), and saturation/coverage reporting.
